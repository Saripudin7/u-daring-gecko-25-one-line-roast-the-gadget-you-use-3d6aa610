# One-Line Roast: The Gadget You Use Every Day

Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — one original line (max 200 characters) roasting a gadget used every day: the wireless earbuds whose charging case dies before the earbuds do.

`main.py` (Python standard library only, no network) writes the roast to `/output/entry.txt`, guarded to a single line of 1–200 characters.

See the [leaderboard](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).
